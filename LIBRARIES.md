# Kullanılan Teknolojiler ve Kütüphaneler

## Frontend Frameworks ve Kütüphaneler

1. **Bootstrap 5.3.0-alpha3**
   - CSS framework
   - Responsive tasarım için kullanılır
   - URL: https://getbootstrap.com

2. **Bootstrap Icons 1.10.0**
   - İkon kütüphanesi
   - URL: https://icons.getbootstrap.com

3. **Chart.js**
   - Grafik oluşturma kütüphanesi
   - Gelir-gider verilerini görselleştirmek için kullanılır
   - URL: https://www.chartjs.org

## Geliştirme Araçları

1. **Serve**
   - Yerel geliştirme sunucusu
   - package.json dosyasında devDependencies olarak tanımlanmıştır

## Tarayıcı Yerleşik Özellikleri

1. **LocalStorage**
   - Tarayıcı tabanlı veri saklama
   - Kullanıcı verileri ve işlemler için kullanılır

2. **DOM API**
   - HTML belge manipülasyonu için kullanılır
   - JavaScript tarafından erişilir

3. **Fetch API**
   - HTTP istekleri için kullanılır (simülasyon amaçlı)

Bu kütüphaneler CDN üzerinden projeye dahil edilmiştir ve yerel olarak saklanmamaktadır.
